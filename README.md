# Dearvell privacy website

Static HTML/CSS site for Dearvell by ZeroSoleil. No JavaScript, trackers, external
fonts, build dependencies or private credentials. Public privacy and account-deletion contact: envisionailabs@gmail.com,
explicitly authorized by the owner on 17 October 2026.

## Publish
Create public repository dearvell-privacy-policy. Upload this directory's contents
to main. In Settings -> Pages choose Deploy from a branch, main, /(root), Save.
For GitHub account rajbizupon, the EXPECTED URL after successful deployment is:
https://rajbizupon.github.io/dearvell-privacy-policy/
Account-deletion page: append delete-account/.
These are expected addresses, not evidence of a live deployment.
